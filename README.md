# Sykkel Kompaniet – Next.js demo

Ny ren prototype bygget med Next.js, TypeScript og Tailwind CSS.

## Start lokalt

```bash
npm install
npm run dev
```

Åpne http://localhost:3000

Produktbilder i denne første versjonen er egne SVG-demoillustrasjoner. De kan byttes direkte med ekte produktbilder senere.
